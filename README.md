# Módulo de Pedidos e Entregas

## Sobre o projeto

Este repositório foi criado como parte da atividade A1 da disciplina de Modelos, Métodos e Técnicas de Engenharia de Software.

## Objetivo

O objetivo deste projeto é apresentar a Estrutura Analítica do Projeto (EAP) de um módulo de pedidos e entregas, organizando as principais entregas necessárias para o seu desenvolvimento.

A EAP está dividida em três níveis, contemplando as etapas de requisitos, projeto, construção e entrega do sistema.

## Arquivos do repositório

- **README.md:** apresenta o objetivo e as informações gerais do projeto.
- **EAP.md:** contém a Estrutura Analítica do Projeto, com as entregas organizadas em três níveis.
